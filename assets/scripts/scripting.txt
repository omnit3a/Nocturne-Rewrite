Scripting System for Nocturne Rewrite

Scripting API Functions
* (register-obj <name>:str <type>:int <callback>:func <id>:int)
  - registers an object in the object definition array.
    the <id> paramater is also used for texture uv lookup.
    <callback> must be a function accepting one input, the interaction type.

* (set-obj-field <field-id>:int <obj-id>:int <value>:<typeof field>)
  - initializes the specified field of the object

* (inherit-obj-fields <dest-id>:int <src-id>:int)
  - copies all the fields of <src-id> into <dest-id>

* (interact-obj-callback <obj-id>:int <i-type>:int)
  - triggers a callback for object with <id> with the specified interaction type (<i-type>).

Modifications/Additions to Fe
* (import <file-name>:string)
  - imports and evaluates a .fe file
  
* (mod <a>:int <b>:int)
  - modulo operation
